# 元件分类规则

## 唯一词表

[分类规则JSON](分类规则.json)是工具读取的唯一分类词表。每类包含“名称”“定义”“边界”；当前覆盖开关、连接器、检测模块、驱动模块。工具不根据别名推测分类，也不把新类型自动归入相近类别。

正式记录的“分类”字段、目录名称必须与词表中的名称完全相同。搜索别名放入“别名”，不能另建“开关类”“接插件”等同义分类目录。词表只覆盖已经出现的真实资料类型，不代表电子电工元件的完整分类体系。

## 路径约定

元件记录严格使用三层路径：

```text
元件/分类/资料编号.json
```

例如，分类为“开关”、资料编号为“cax-mts103-d2-bkjl”的记录，路径只能是：

```text
元件/开关/cax-mts103-d2-bkjl.json
```

不直接放在 元件/ 下，不增加型号或版本子目录。硬件版本通过独立资料编号及字段区分。文件名必须完整匹配资料编号，并使用小写 `.json` 扩展名；资料编号仍只允许小写字母、数字和连字符。

## 新增与调整

1. 先确认真实元件无法归入现有类别，在本地候选中记录分类理由。
2. 在已授权的收录范围内，为新类补充唯一名称、定义及边界，不预建空目录。
3. 更新分类规则JSON，真实记录按新类的三层路径保存；更新相关说明和分类边界测试。
4. 运行测试、生成索引并检查，确认既有记录仍符合规则。

分类重命名须同时更新词表、正式记录的分类字段和所在目录，并重新生成索引。工具只报告错误，不自动移动、重命名或删除资料。

## 校验边界

分类文件缺失、格式错误、空词表、同名分类、缺少定义或边界时，检查、索引生成及检索均失败，不能回退到硬编码词表。

工具验证登记名称和路径的一致性，不自动判断元件的物理用途分类是否正确；类别选择仍需根据实际资料核对。分类文件同样受到 UTF-8、体积和隐私检查。
