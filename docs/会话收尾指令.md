# 会话收尾指令

## 日常收尾

把下面内容发给刚完成元件任务的会话。已有本地仓库时复用，不重复克隆；先核对 origin 是否为指定仓库。找不到本地目录时可读取远程规则，再选择独立目录准备候选，不能把其他项目的远程地址改成此仓库。

```text
请读取 https://github.com/LKC218/component-reference-kb 的 README.md、AGENTS.md 和 docs/收录规范.md，整理本会话找到的元件资料。

1. 只收录元件网站、实拍、图纸和 CAD 获取地址；不收 CAD 本体、压缩包、生成模型、转换网格及软件教程。
2. 先核对完整型号与硬件版本，标记已核实、待核实、已排除；保留来源网址、核对范围、限制、会话出处及实际文件指纹。分类读取 docs/分类规则.json，正式记录路径与分类、资料编号必须一致。
3. 在本地会话候选目录整理，检查已有元件后由一个整合会话合并；第三方公开分发依据不明时只保留链接，不复制原件。
4. 按轻量预算核对附件，生成索引并运行检查；报告新增、更新、重复、冲突、缺失与体积变化。
5. 先交付本地候选，不自动提交或推送，不修改原始资料和其他项目配置。
```

## 需要同步远程时

工程师确实准备发布时，再追加：

```text
将本次知识库变更提交并推送到 LKC218/component-reference-kb，只包含本次整理的文件。先检查差异、来源与附件体积，使用中文 Conventional Commit；报告分支、提交哈希及推送结果。
```

## 智能体执行检查

Python 3.10 以上，无需安装依赖：

```text
python scripts/资料库.py index --write
python scripts/资料库.py check --report 本地/检查报告.json
python scripts/资料库.py search "完整型号或别名"
```

报告路径已存在时拒绝覆盖，应换用新的文件名。生成索引只替换派生索引，不替换事实记录。

## 多会话同时完成

各会话使用自己的 本地/待整理/会话编号/，不同时修改正式资料或总索引。候选没有合并及通过检查前，回复“候选已整理”，不能回复“已入库”。只有实际推送成功后才能回复“已同步 GitHub”。
