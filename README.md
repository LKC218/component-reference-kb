# 元件资料知识库

为人工与 AI 智能体保存可追溯的元件资料，优先按完整型号定位，再按别名和类别查找。

远程仓库：https://github.com/LKC218/component-reference-kb

## 收录范围

收录元件网站、实拍、图纸和 CAD 获取地址；采用轻量索引与必要的小附件。CAD 本体、压缩包、生成模型、转换网格和 Blender、Three.js 方法资料均不收录。

当前初始化样例从已有项目的来源清单和元件说明回收，只保存自行整理的记录及来源链接，没有复制第三方图片、PDF 或 CAD。样例包含核对方式、会话出处与版本限制，不表示本轮重新完成全部网站核验。

## 快速使用

需要已有 Python 3.10 或以上及 Git，无第三方依赖，不自动安装软件。在本仓库根目录运行：

```text
python scripts/资料库.py check
python scripts/资料库.py search "三档光开关"
python scripts/资料库.py search "INA219EVM" --all-statuses
```

默认搜索已核实的元件记录。`--all-statuses` 同时显示待核实、已排除记录；已核实记录内仍可能包含待核实或已排除来源，使用前必须阅读返回的原始记录及限制。

## 目录入口

| 位置 | 用途 |
| --- | --- |
| [收录规范](docs/收录规范.md)、[分类规则](docs/分类规则.md)、[字段说明](docs/资料字段说明.md) | 范围、分类、状态、证据、空间和字段约定 |
| [会话收尾指令](docs/会话收尾指令.md) | 给当前任务或其他会话复制使用的话术 |
| 元件/、网站/ | 唯一的正式资料记录，按型号或网站分别保存 |
| 索引/资料索引.json、[资料模板](模板/元件资料.json) | 自动生成的检索入口与填写样例结构 |
| [工具说明](scripts/脚本使用说明.md)、[代码导航](docs/apps-code-map.md) | 检查、检索、索引生成和维护入口 |

首次收录真实附件时再创建 附件/；不预建空的元件模块。`本地/` 被 Git 忽略，用于会话候选、原件留档、私有配置与检查报告，不是远端可用的公共资料。

元件记录统一使用 `元件/分类/资料编号.json`，目录分类、JSON分类字段和资料编号文件名必须一致。[分类规则JSON](docs/分类规则.json)是工具读取的唯一词表，首版包含开关、连接器、检测模块和驱动模块。未登记分类、错放目录、多余层级或文件名错配会阻止检查、索引生成和检索；新增真实类型按[分类规则](docs/分类规则.md)扩充词表。

## 任务结束后怎样收录

1. 阅读 AGENTS.md、收录规范与分类规则，用模板在本地生成本会话候选。
2. 查找已有型号及硬件版本，核对来源，保留已排除资料的理由。
3. 一个整合会话将候选写入正式记录，必要的小附件先核对分发依据与可读性。
4. 运行 `python scripts/资料库.py index --write`，再运行 `python scripts/资料库.py check`。
5. 报告新增、更新、冲突、缺失与体积变化；按工程师授权决定是否提交和推送。

## 体积与获取能力

图片不超过 300 KiB，PDF 不超过 2 MiB，文本文件不超过 1 MiB，工作文件合计不超过 100 MiB。检查也统计 Git 历史对象大小；本地缓存和 Git 对象单独列出，不混入工作文件预算。

CAD 获取地址可以指向官方页面或官方压缩包，但仓库不存其内容。原图、原件或网站不可访问时报告缺失，不自动降清晰度、不推测尺寸、不绕过登录限制。仓库能够离线检索已收录的文字，链接资料与未收录附件仍需联网及对应权限。

## 维护边界

新增或修改功能工具同步 [代码导航](docs/apps-code-map.md) 和 [工具说明](scripts/脚本使用说明.md)。数据记录不授予第三方图片、图纸或 CAD 的再分发权；每个实际附件必须记录独立依据。仓库目前没有为第三方资料指定统一许可证。
